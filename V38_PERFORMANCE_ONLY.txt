V38 — PERFORMANCE/SMOOTHNESS ONLY
BASE: V36 (approved visual baseline)

FIXED:

1) Gallery open/close jump
- Unified preview/open/closing intrinsic top geometry from 64px/50px conflict to one 50px value.
- Preview compensation is now -50px.
- Bottom gradient/blur and VIEW ALL WORK overlay compensation changed 64 -> 50.
- Net on-screen preview position stays the same.
- No layout-height change occurs when gallery-mode is toggled.

2) Native gallery scrolling
- NO artificial smooth-scroll / wheel interception.
- --work-scroll is no longer rewritten every scroll frame while gallery is open.
- It is still captured explicitly before BACK / navigation.

3) Media work during scrolling
- Removed per-scroll gallery-card loop and offsetTop reads.
- Removed forced video.load() calls from scroll path.
- Nearby media uses IntersectionObserver + idle queue.
- While gallery is actively scrolling, gallery videos are paused.
- Playback resumes 150ms after scrolling stops.
- Concurrent playback cap: 1 mobile / 2 desktop.
- Gallery videos do not start while gallery/page transition is active.
- Warming after gallery-mode-change is delayed until the visual transition has finished.

4) Mobile page swipe
- Removed the blocking non-passive touchmove preventDefault listener.
- Existing touchstart/touchend threshold/direction logic is unchanged.
- Gallery touch scrolling remains native.

5) Page transition final-frame snap
- Existing V36 trajectory/easing stays unchanged.
- Final JS transform is held for one full paint frame before inline transforms are removed.

6) Startup PANXRT blink
- The moving handoff now uses a clone styled from the REAL menu wordmark.
- It lands pixel-aligned on the real PANXRT.
- The real target is revealed underneath the aligned clone, then the clone is removed one frame later.
- No end-frame swap between two different word renderings.

NOT TOUCHED:
- V36 submenu overlay structure
- submenu frosted glass
- mobile horizontal submenu scrolling
- colors / typography / card geometry
- WORK matte
- menu layout
- WORK/CONTACTS visual design
- gallery card crop/hover
- project/case content
