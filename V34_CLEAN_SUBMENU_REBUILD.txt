V34 — CLEAN SUBMENU REBUILD FROM V28

This version does NOT reuse the legacy submenu classes.

DOM:
submenu-mask         stationary 50px clip window below main header
└── submenu-sheet    only moving object (top: -50px <-> 0)
    ├── submenu-glass     rgba(.58) + blur(20px) + saturate(125%)
    └── submenu-controls  ALL / MARKETPLACE / BRAND & CAMPAIGNS / MOTION / POSTERS

Why this is different:
- Old .filter-reveal / .gallery-filters CSS cannot affect the new submenu.
- The mask never moves and starts strictly at top: var(--header).
- The sheet moves by TOP rather than transform, avoiding the transformed
  backdrop-filter compositor problem seen in earlier versions.
- Glass and text are siblings inside the SAME moving sheet, so they can never
  separate or animate at different times.
- The mask has overflow:hidden, so neither glass nor text can appear above
  the main header while closing.
- --filter-left still clips the submenu behind the physical side rails.

Preserved from V28/V26:
- PANXRT / WORK-spine clipping behavior
- WORK matte/header
- page transition timing
- compact 50px submenu size and left alignment
- gallery/grid/cards/crop/hover
- bottom gradient/blur
- startup/loading
- cases/media

All local CSS/JS references use ?v=34.
